# Amazon Mart Sales Analysis Dashboard

## Project Overview

This project is an Excel-based sales analytics dashboard created for analyzing the business performance of Amazon Mart. The workbook contains raw transactional sales data along with multiple analytical dashboards and visual reports to evaluate sales, profit, discounts, shipping performance, regional trends, and customer segmentation.

The dashboard helps businesses and analysts gain insights into:

* Sales performance across regions and categories
* Profit analysis by segment and sub-category
* Impact of discounts on profitability
* Shipping mode efficiency
* Monthly sales and profit trends
* Country-wise and region-wise sales distribution
